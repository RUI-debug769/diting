# 谛听 · 3D 打印外壳（T5AI-Core DevKit + 18650）

按 `/tmp/pet2/c5.png` 的 20×18 像素精灵取形，做成 FDM 可打印的两片式外壳：
正面是**像素脸**（凸起的描边 + 内凹面板 + 奶白眼片 + 珊瑚色"芽"），内部装 **TuyaOpen T5AI-Core DevKit** 与一节 **18650**。
**本方案不含喇叭**（按需求取消），因此没有前腔和出声孔。

```
hardware/shell/
├─ params.py        全部参数（改这里，不碰几何代码）
├─ spr.py           像素网格 → 轮廓多边形（20×18 采样自 c5.png）
├─ model.py         建模主程序：rounded_body / make_front / make_back / make_horn / make_eye / make_button
├─ validate.py      干涉校验（前/后/芽/眼/键 × 板/电池）
├─ preview.py       正交三视图 + 剖切（无需 3D 后端）
├─ figures.py       交付插图
├─ out/             交付文件：5 个 STL + 5 个 STEP
└─ preview/         插图
```

## 1. 外形

| 项目 | 数值 |
|---|---|
| 外形（宽×高×厚） | **104 × 97.5 × 44 mm**（含芽时高 110.5） |
| 像素格 | 6.5 mm/格，20×18 精灵 |
| 壁厚 | 2.4 mm |
| 分模面 | Z = 22（厚度的正中间），后盖裙边搭接 4 mm |
| 前后大圆角 | R2.6（按截面内缩 loft 出来，**不是** CAD 圆角——像素阶梯的凹角做不了 fillet） |
| 前脸 | 整体内凹 0.9 mm，四周留 4 mm 边 → 凸边即像素描边 |
| 眼片 | 12.8 × 12.8 × 1.6 奶白件，眼窝单边间隙 0.28 |
| 芽 | 26×26 台阶 + 13 宽触角，独立珊瑚色件，靠两条槽套住前后壳的榫 |

## 2. 内部布局

坐标系：X 左右、Y 向上（Y=0 脚底）、Z 从前脸往后（Z=0 前脸外表面）。

- **主板**：装在前壳内壁，**元件面朝前**（麦、按键、指示灯都贴着前脸）。
  板 67.5×28.04，排针朝后伸到 Z=19.51；靠"两条侧壁 + 两条排针承托条 + 上挡块 + T5-E1 压罩凸台"固定，**不用螺丝、不用胶**。
- **麦克风**：板载 Ø6 驻极体（穿过 PCB），轴线 (-6.5, 49.55)，前脸开 Ø4.6 导音孔，正对两眼之间。
- **按键**：USER/P29 与 RST 两个轻触键在 (5.42, 46.1) 与 (5.42, 51.4)，前脸做 Ø4.6 沉孔 + Ø3.2 通孔，配 Ø4.5 打印按键帽。
- **指示灯**：PWR / CRG 两颗贴片 LED 正对前脸 0.55 mm 薄壁窗（透光不开孔）。
- **USB-C**：插头从**底面**（两脚之间的凹口）进，窗口 10.2 宽 × 3.4 高。
- **电源开关**：同样从底面拨动，窗口 10.7 × 6.2。
- **电池**：18650（Ø18.4 × 65）横放（轴沿 X）在**后盖**里，中心 (0, 40, 31.8)，两端 2 mm 挡筋限位。
  理由：前壳被 67.5 长的板 + 10.5 的排针占满，19.2 的电池只有后盖放得下。
- **合盖**：后盖 4 片卡舌 + 前壳侧壁 4 个 Ø2.2 球卡点（干涉 0.15），合上"咔"一声；底面留撬盖缺口。
- **芽**：前后壳在头顶各伸出一条 1.3×12×3 的榫，插进芽底面两条槽。

## 3. 打印

| 件 | 数量 | 建议方向 | 支撑 |
|---|---|---|---|
| `front.stl` | 1 | 前脸朝下（Z=0 贴床） | 不需要 |
| `back.stl` | 1 | 后背面朝下（z=44 贴床） | 不需要 |
| `horn.stl` | 1 | 芽的脚底面朝下 | 不需要 |
| `eye.stl` | **2** | 平面朝下 | 不需要 |
| `button.stl` | **2** | 法兰朝下 | 不需要 |

- 材料 PLA / PLA+ / PETG 均可；层高 0.2，壁厚 3 圈（≥1.2 mm），填充 15%。
- 前脸是**大面积首层**，建议 5 mm brim、热床 60 °C，避免翘边把像素边拉变形。
- 卡点与榫建议 0.16 mm 层高、速度降到 40 mm/s，保证配合手感。
- 体积/耗材估算：前 35.0 + 后 42.0 + 芽 12.1 + 眼 0.5 + 键 0.1 ≈ **90 cm³ 实体**；15% 填充约 **48 g**。

## 4. 装配

1. **眼片**：从内侧压进眼窝（0.28 间隙），平齐前脸即可，可点一滴胶。
2. **按键帽**：从内侧把 Ø3.1 杆穿过 Ø3.2 孔，Ø4.5 法兰落在沉孔里。
3. **主板**：斜着把 USB 端落进底面开口，再把板压向排针承托条（排针尖端 Z=19.51）；侧壁间隙 0.36 自动居中，T5-E1 屏蔽罩会卡进压罩凸台。
4. **电池**：JST 插到板上 BAT 座（**注意红黑极性，反接会烧板**），电池横进后盖的两道挡筋之间，导线沿后盖内壁走向前壳。
5. **合盖**：后盖裙边对准前壳台阶，四周均匀按下，听到 4 声"咔"；拆的时候从底面撬盖缺口用指甲撬开。
6. **芽**：底面两条槽对准头顶两条榫，压到底（可点胶）。
7. **开机**：底面窗口拨 ON/OFF；充电从底面插 USB-C。

> 装配顺序建议：先装眼片/按键帽 → 装板 → 接电池 → 试通电（灯亮、按键有事件）→ 合盖。

## 5. 改参数

全部在 `params.py`，改完 `python model.py` 重出 STL/STEP（约 11 s）。

| 想改 | 改哪里 |
|---|---|
| 整体大小 | `P`（一格多少 mm），整机随比例缩放 |
| 厚度 | `D`；`SPLIT_Z` 取 `D/2` |
| 壁厚 | `WALL` |
| 前脸凹深 / 留边 | `FACE_RECESS` / `FACE_RIM` |
| 眼片大小 | `EYE_W`；眼窝深度 `EYE_POCKET` |
| 电池型号 | `BAT_D` / `BAT_L` / `BAT_CY` / `BAT_CZ`（换 18500 或软包时改这四个） |
| 板的位置 | `BOARD_Y0`（上下）、`BOARD_Z0`（前后） |
| 按键/麦/灯位置 | `MIC_C` / `BTN_USER_C` / `BTN_RST_C` / `LED_PWR` / `LED_CRG` |
| 要不要喇叭 | `HAS_SPEAKER`（当前 False；True 需另加前腔与出声孔，本版未实现） |

## 6. 已做的校验

`python validate.py` 用官方 STEP 的 18 个器件包围盒当代理（直接布尔 37 MB STEP 会卡死），逐对求交：

```
front × board       0.000 cm³
back  × board       0.000
front × battery     0.000
back  × battery     0.000
front × back        0.000
horn  × front/back  0.000
button × front      0.000
eye   × front       0.003   （三角化伪影，设计间隙 0.28）
```

STL 闭合性：`back / horn / eye / button` 完全流形；`front` 有 8 条**零长度边**（球卡点的极点三角化伪影，切片器会自动丢弃，不影响打印；STEP 本体 `is_valid=True`）。

## 7. 已知限制

- 芽做成"沿厚度贯通的冠"而不是细柱：因为头顶 Y78.5..84.5 处被 T5-E1 模组顶住，细柱没有落脚点。
- T5-E1 的天线 FPC 在 STEP 里是刚性的（伸到板外 6 mm），本设计把板整体下移 1.4 mm 并在屋顶开了 1.0 深的让位槽；实机装配时若 FPC 顶到顶壁，向上折一点即可。
- 底面两个窗口（USB / 开关）是连通的凹口，从正下方能看到一点板边，属正常。
