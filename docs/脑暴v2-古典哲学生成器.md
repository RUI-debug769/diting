## 1. 方法：哲学做「约束」，不做「皮肤」

一个作品是不是「贴皮国风」，用三个问题就能验：

1. **删掉哲学，它还成立吗？** 成立 → 哲学是装饰，扔。
2. **10 秒内，一个没读过原典的人能感到「不对劲」吗？** 不能 → 命题太绕，改。
3. **AI 拿掉，它还一样吗？** 一样 → 这不是 AI 作品，是机电玩具。

再加一条你自己的算子（来自共享记忆）：**它必须有一处故意低效、不可量化、不可复制**（O5）。古典哲学天然反可计算——这是你和「AI 效率叙事」之间最锋利的那道缝。

## 2. 六支哲学的「生成法则」

不是主题词，是**能直接拿去生成动作的规则**。

| 支 | 核心命题（原典） | 生成规则（拿去筛/生成 idea） | 最容易被做成的俗套 |
|---|---|---|---|
| **道家** | 反者道之动（老 40）；听之以气（庄·人间世）；虚室生白；大音希声 | 主动作必须是**不做 / 退让 / 减损**；用户越用力，系统越退 | 太极图、水墨屏保、「禅意」香薰 |
| **易·五行** | 生生之谓易；穷则变，变则通；易有三义（简易/变易/不易） | 把**关系**做成物理规则：生克、循环、变易；系统要能推演，不能只贴五色 | 风水罗盘、算命签、五行配色文创 |
| **禅宗** | 实无功德（景德传灯录）；拈花微笑；吃茶去；无门关 | 设计一个**不可说的瞬间**；装置必须**拒绝解释自己**；AI 的作用是「不回答」 | 电子木鱼玩具、佛系文案、赛博佛像 |
| **儒家礼乐** | 和而不同（论语·子路）；致中和（中庸）；声音之道与政通（乐记） | 把**关系/秩序**做成必须两人以上才能完成的动作；一个人玩不转 | 汉服拍照、编钟摆件、国学机 |
| **山水文人** | 卧游（宗炳）；三远（郭熙）；虚实相生（笪重光）；留白 | 不画山水，**让你用山水的看法看眼前**；装置是「看的方式」 | 水墨屏、山水投影、国风台灯 |
| **墨家/工匠** | 衡而必正（墨经）；景到在午有端（墨经·光学）；机关术；一诺千金（史记） | 让**结构本身**成为表达；AI 负责生成/求解/校验，机械负责诚实 | 鲁班锁钥匙扣、榫卯台灯、机关盲盒 |

**组合原则**：一支为主（决定命题），一支为辅（决定形态）。两支以上平铺 = 文化拼盘，评委会闻出来。

## 3. idea 池：60 条（先不判可行性）

格式：**编号 · 名称** ｜ 算子 ｜ 原典 ｜ 机制 + AI ｜ 10 秒演示 ｜ 雷。
算子沿用上一版的 O1–O8（O1 减法徽章 / O2 结界 / O3 幻想严肃性 / O4 人格优先 / O5 反可计算 / O6 显式建模 / O7 智识密度 / O8 时间可见）。

### A. 道家（1–10）

1. **听息** ｜O2·O5·O8｜庄子「无听之以耳而听之以心，无听之以心而听之以气」｜无按钮；麦克风只分「呼吸」与「说话」，呼吸→灯明暗，开口→灯暗｜凑近呼吸，灯亮；说一句话，灯暗｜雷：很容易被当成声控灯，AI 太薄。
2. **反者道之动** ｜O5·O2｜老子 40「反者道之动；弱者道之用」｜悬挂铜片 + 距离传感；你伸手它退，你收手它回；AI 预测「伸手意图」而不是等碰｜伸手三次，三次退｜雷：像逗猫棒，命题撑不住三层追问。
3. **虚室生白** ｜O1·O5｜庄子「瞻彼阕者，虚室生白」｜灯只照亮桌面空处；放东西，光让开；AI 做桌面分割，算「负空间」｜手放上去，光退开；手拿开，光回来｜雷：摄像头模块是否发放未确认；投影成本高。
4. **大音希声** ｜O5·O8｜老子 41「大音希声，大象无形」｜一台「越安静越响」的乐器：你停下，它才发出一个音；你越弹，它越沉默｜停手三秒，一声；再弹，无声｜雷：评委可能以为坏了；演示节奏极难控。
5. **吾丧我** ｜O3·O5｜庄子·齐物论「今者吾丧我」｜铜镜/小屏里的脸逐渐淡去，只剩轮廓；AI 做人脸擦除/风格化，越看越少｜看三秒，脸没了｜雷：需要屏；容易变成「恐怖镜」。
6. **庖丁解牛** ｜O7·O1｜庄子·养生主「依乎天理，批大郤，导大窾」｜一把刀形工具，沿纸/木的纹理滑动时发出「顺」的声音，逆纹则涩；AI 识别纹理方向｜顺着划，声音顺；逆着划，卡住｜雷：AI 只是分类器；效果太细，10 秒看不出来。
7. **上善若水** ｜O2·O8｜老子 8「水善利万物而不争」｜小水盘 + 微型泵；水位随你说话的语气涨落，不显示数字；AI 做语音情感→泵｜说一句软话，水涨；说一句硬话，水落｜雷：水泵/漏水/展会运输；情感映射容易被质疑。
8. **朴** ｜O1·O5｜老子 28「朴散则为器」｜一块原木，只有你知道怎么开：敲三下（节奏口令）才弹开，里面是一个极小机关｜敲三下，木开｜雷：像解谜玩具；AI 只是节奏匹配。
9. **逍遥游** ｜O3·O2｜庄子·逍遥游｜磁悬浮的小物件，随房间声音飘；声音大→高，安静→低｜悬浮着，随一声轻响升起｜雷：磁悬浮模块 50 元起，现场易受干扰；两天半赌不起。
10. **知止** ｜O5·O6｜老子 44「知止不殆，可以长久」｜你越推它越不动，松手它走一步；AI 判断「力」与「意图」的差别｜推不动；松手，走一步｜雷：像坏了的玩具；命题要讲很久才懂。

### B. 易与阴阳五行（11–20）

11. **五行盘** ｜O7·O6｜五行生克；《洪范》五行｜五枚材质 token（木/火/土/金/水）放上圆盘，触发相生或相克的光与声；AI 推演「象」并说一句，不判吉凶｜放木+火→暖光亮；放水+火→光熄｜雷：最容易滑向风水文创；必须坚持「不占卜、只推演」。
12. **善易者不卜** ｜O6·O5｜《荀子·大略》「善为易者不占」｜摇卦筒，AI 不给吉凶，只给**三种可能的象**，每种标注置信度，并说明它依据哪一爻｜摇一次，出三象，各带百分比｜雷：评委可能只想要「准不准」；要顶住。
13. **阴阳鱼** ｜O2·O8｜太极图；《易》一阴一阳之谓道｜双色转盘，转速由两个人的声音差异决定：越不同越转，越相同越停｜两人说话，盘转；同时说同一句，盘停｜雷：AI 只是比较；装置像科学展品。
14. **一叶知秋** ｜O8·O1｜二十四节气；《淮南子·天文训》｜一片叶子每天变一点色/形，快进模式看一年；AI 按节气生成色与形态｜快进，叶从绿到枯｜雷：时间尺度太长；快进会削弱「等」的命题。
15. **洛书九宫** ｜O7·O5｜洛书；九宫算｜3×3 磁吸块，摆错则一块弹起；AI 只给「哪一类错了」，不给答案｜摆错，弹起；再摆，再弹｜雷：像益智玩具；文化层只有「数」。
16. **五音** ｜O7·O2｜宫商角徵羽；《礼记·乐记》｜五个音块，按五行生克组合成一段旋律；AI 编配，不重复｜放两块，出一段；换顺序，变调｜雷：像音乐玩具；五行与五音的对应要考据准。
17. **三易** ｜O6·O7｜郑玄《易赞》简易/变易/不易｜一个三档旋钮：变易=每次不同，不易=恒定，简易=一条规则；AI 解释当前档并暴露规则｜转三档，三种行为｜雷：太抽象；10 秒内难以感知差异。
18. **观象授时** ｜O7·O1｜《尚书·尧典》「历象日月星辰」｜小圭表，灯当太阳，影子长度换算节气/时辰；AI 读出并解释｜移动灯，节气变｜雷：AI 只是查表；室内光源不真实。
19. **河图** ｜O7·O1｜河图；《系辞》「河出图」｜1–10 石子排列，摆对才全亮；AI 讲河图与五行的对应｜摆对，全亮｜雷：静态；演示只有一次「对了」。
20. **卦气** ｜O8·O1｜十二消息卦；《易纬·稽览图》｜一面墙 12 格，随月份亮/暗；AI 讲消息卦与物候｜快进一年，格逐一亮暗｜雷：墙面装置，运输与场地不允许。

### C. 禅宗（21–30）

21. **并无功德** ｜O5·O7｜《景德传灯录》达摩对梁武帝「实无功德」｜电子木鱼：每敲一下，前一下的「功德」消失；108 下后显示「无」；AI 从节奏/力度判断你是不是在「求功德」，回一句公案｜敲三下，它说「实无功德」；越敲越快，它说「你在数」｜雷：像文创玩具；宗教敏感度要拿捏。
22. **拈花** ｜O2·O5｜《五灯会元》拈花微笑，唯有迦叶｜房间安静三秒，花慢慢开；有人说话/噪音，花合；AI 做声音事件检测（可选声纹：只认你的安静）｜静三秒，花开；评委一说话，花合｜雷：会场很难安静；AI 太薄。
23. **数息** ｜O8·O2｜智者《修习止观坐禅法要》六妙门「数」｜数呼吸到十归零，不累积；灯一下一下；AI 做呼吸检测｜呼吸三次，灯三下｜雷：演示要一分钟；「不累积」的命题要讲才懂。
24. **吃茶去** ｜O2·O5｜《五灯会元》赵州「吃茶去」｜小茶炉，只在你说「吃茶去」时煮一杯；说别的它不理；AI 做意图/关键词识别｜说一句，水开；说别的，无反应｜雷：加热/出水硬件；现场食品安全。
25. **指月** ｜O1·O5｜《楞严经》「如人以手指月示人」｜小灯臂指向窗外的月亮（或天花板上的「月」）；它不解释；AI 算月相/方位｜灯臂转，指向月｜雷：AI 只是天文计算；阴天/白天失效。
26. **无门关** ｜O5·O7｜无门慧开《无门关》｜一个没有门的盒子，只有一条缝；你把烦恼说进去，它吞掉，不回；AI 做语义→销毁（真删）｜说一个烦恼，它吞，无声｜雷：演示几乎没有反馈；评委可能觉得没做完。
27. **枯山水** ｜O1·O2｜禅庭；《园冶》借景｜磁力小球在沙上耙出纹样，纹样由你的呼吸/声音生成，每天被抹平；AI 生成纹样｜说一句，沙上出现一道；静一会儿，纹样长出来｜雷：两轴机械 + 沙，运输与精度；但视觉最强。
28. **十牛图** ｜O8·O3｜廓庵师远《十牛图颂》｜十个阶段的灯，你每完成一次「静坐」亮一格；AI 判断你是否真的静｜快进十格｜雷：需要长期使用；两天半只能演「快进」。
29. **棒喝** ｜O2·O4｜临济「喝」、德山「棒」｜你走神时，装置轻敲你一下（香板）；AI 检测注意力/低头｜低头看手机，被敲｜雷：伦理与安全；评委可能反感。
30. **空** ｜O5·O6｜《心经》「色即是空」｜透明盒，里面什么都没有；伸手进去，它给你一段「空」的声音；AI 生成「无」｜伸手，一声/无声｜雷：太虚；10 秒内没有可看的。

### D. 儒家礼乐（31–40）

31. **和而不同** ｜O2·O7｜《论语·子路》「君子和而不同」；《国语》「和实生物，同则不继」｜两个人各对一个孔哼唱，装置生成第三声部；保留两人音色，不抹平；AI 做声部分离+基频+和声｜两人哼两个不同的音，第三声出现；两人唱同一个音，第三声消失｜雷：会场噪音；延迟；需要两人配合。
32. **投壶** ｜O2·O7｜《礼记·投壶》｜投壶游戏，AI 做「礼官」：报分、请让、罚茶，流程比输赢重要｜投一箭，礼官唱名｜雷：容易被当成游戏；礼的部分要真做。
33. **编钟** ｜O7·O2｜曾侯乙编钟「一钟双音」｜3D 打印小钟 + 电磁敲击，AI 奏一段礼乐；一钟双音｜敲一声，双音｜雷：成本/调音/时间；两天半风险高。
34. **中和** ｜O5·O6｜《中庸》「致中和，天地位焉」｜两个音叉/两个音，AI 调到「中和」（不刺耳也不闷），显示偏离度｜调一下，和｜雷：效果太细；像调音器。
35. **克己复礼** ｜O2·O6｜《论语·颜渊》「克己复礼为仁」｜手机盒，只有完成一套「礼」的动作（洗手/正坐/三息）才打开；AI 做姿态/顺序识别｜跳步，不开；做完，开｜雷：像自律 App 的硬件版；说教味。
36. **乡饮酒礼** ｜O7·O6｜《仪礼·乡饮酒礼》｜三人以上座次装置，坐错不亮；AI 讲尊卑/齿序（可批判）｜换座，灯变｜雷：等级争议；现代观众可能不适。
37. **六艺** ｜O7·O2｜礼乐射御书数｜六个小关卡，AI 当「师」；现场只做「射/书」｜一关｜雷：散；每关都浅。
38. **家训** ｜O1·O7｜《颜氏家训》｜输入你家的一件事，AI 写一句家训，刻/印在木牌上｜一句话→一块牌｜雷：刻字时间；生成容易空泛。
39. **冠礼** ｜O2·O8｜《仪礼·士冠礼》｜三次加冠，灯逐次亮；AI 念祝辞｜三次｜雷：仪式太长；观众代入感弱。
40. **乐记** ｜O6·O7｜《礼记·乐记》「声音之道，与政通矣」｜一段音乐，AI 分析其「治/乱」（音阶/节奏），并承认这是建模｜一段乐，一段判词｜雷：文化争议大；AI 判「治乱」容易翻车。

### E. 山水文人（41–50）

41. **留白** ｜O1·O5｜笪重光《画筌》「虚实相生，无画处皆成妙境」｜灯只照空处；桌面越空，光越多；AI 做桌面分割｜清空桌面，光亮起来｜雷：摄像头未确认；与 3 重复，二选一。
42. **卧游** ｜O2·O8｜宗炳《画山水序》「卧以游之」｜躺下，天花板上的山水随呼吸展开/收拢；AI 生成山水｜躺，山长｜雷：投影成本；仰卧在展台不现实。

## 6. Top 1：称心（一句话的重量）

> 一句话：**它称的不是话，是你说这句话时的可信。**
> 母题的「？」：**AI ＋ 文化 ＋ 信**

### 6.1 为什么是它

- 它同时满足你的三条硬约束：**宋式器物**（戥子/铜/木/瓷，无屏）、**反可计算**（永远不显示克数）、**只属于我**（每句话的判词都引用你自己的词）。
- 它是六个支里唯一一个把「哲学」做成了**物理动作**的：秤杆倾斜，是不可伪造的。
- 它最便宜：物料 ≤ 40 元，且不需要屏、不需要打印机、不需要摄像头。
- 它有一个 10 秒内能让人「回不过神」的反转：**越用力发誓，越轻。**

### 6.2 原典与命题三层

- **文化层**：《史记》「得黄金百斤，不如得季布一诺」；《论语》「民无信不立」；《墨经》「衡而必正」。中国人对「信」的执念，第一次被做成一件可以「称」的器物。
- **机制层**：它称的不是「诚意」，是「可信」。诚意可以表演，可信不能。所以「我发誓我绝对……」反而轻——**过度补偿本身就是不可信的信号**（老子 17：「信不足焉，有不信焉」）。
- **哲学层**：如果一句话的重量可以被计算，它还叫「信」吗？——装置的回答是：**它只倾斜，不给数字。** 这是 O5 的物理化。

### 6.3 形态与交互

- 一杆黄铜戥子（或 3D 打印仿古杆秤），左盘中央一个小孔（麦克风），右盘是游砣；底座一枚暖光小灯；**没有屏、没有数字**。
- 唯一动作：**对着盘中的小孔说一句话**（3–8 秒）。说完，游砣自己走到某个位置，秤杆倾到一个角度，停 1 秒。
- 三档：轻（几乎平）/ 中（微倾）/ 重（明显倾）。
- **不确定时，秤杆来回摆**（幅度=置信度的反面）。这是 O6：它暴露自己在猜。
- 然后一句判词（语音，或打在一张小纸片上）：「你说了三次『一定』。」「这句有两处停顿。」「你没说时间。」

### 6.4 AI 在哪（不深，但拿不掉）

1. **ASR**：sherpa-onnx + SenseVoice（中文，整段，非流式）。
2. **韵律**：opensmile / librosa 提停顿、语速、音高抖动、填充词（「嗯」「那个」）。
3. **语义**：LLM 判断——是否承诺、是否给出时间/条件、是否过度修饰、是否有具体名词。
4. **判词**：LLM 输出 0–100 的「信」分 + 一句判词，**必须引用原话中的一个具体词**，否则重写。
5. **执行**：分数 → 舵机位置（0–100 映射到 0–30°）；置信度 → 摆动幅度。

**为什么拿不掉**：拿掉 AI，秤只会随机倾斜；「越发誓越轻」这个反转就不存在。

### 6.6 现场 90 秒

- 0–10 秒：把戥子放桌上，灯亮着，秤杆静止。不说话。
- 10–25 秒：「它是一杆秤。但它不称重量，它称一句话。」
- 25–45 秒：评委说「我明天一定到」→ 秤杆慢慢倾到中档，判词：「你给了时间。」
- 45–65 秒：评委说「我尽量吧」→ 秤杆几乎不动，判词：「你没给时间。」
- 65–85 秒：评委说「我发誓我绝对会来」→ 秤杆**反而更轻**，判词：「你说了两次『发誓』。」停两秒。「信不足焉，有不信焉。」
- 85–90 秒：「它从不告诉你几克。」

### 6.7 会杀死它的四个点

1. **机械回中/摩擦**：秤杆倾了不回，或回不准。→ 对策：轴承 + 配重；三档而不是连续角度；11/4 先做纯机械验证。
2. **会场噪音让 ASR 崩**：→ 对策：近讲（嘴离孔 10 cm）；板载麦 + 指向性海绵套；判词允许「听不清，再说一次」。
3. **判词像算命**：→ 对策：每句判词必须引用原话里的具体词；不用「你内心」「命运」这类词；把特征打在纸上，让评委看见依据。
4. **评委说「AI 只是分类器」**：→ 对策：承认。然后说：「对，它是一个可被反驳的分类器。它把依据给你看，你可以说它错。」——这正好是 O6。

## 8. 与谛听 / 零点的关系：一条脊柱，三个壳

**关键判断**：谛听、零点、称心，技术脊柱是同一根——

```
采音（板载麦/INMP441） → ASR（sherpa-onnx） → LLM（llama.cpp / 手机端）
        → 执行器：灯 / 舵机 / 热敏打印机
```

差别只在**壳**与**判词**。所以：

- 11/4–11/5 先把脊柱跑通（一句话 → 文字 → 一句判词 → 一个动作），**壳可以晚一天定**。
- 但评审看「比赛期间增量」，不能三个都做；11/5 上午必须押一个。

**决策表**：

| 11/4 的实验结果 | 选 |
|---|---|
| 热敏打印机中文通 + 你想要最重的叙事 | **零点**（会遗忘的机器） |
| 打印机不通 + 你想要最稳的交付 | **谛听**（桌面版） |
| 你想要最高分、最便宜、最像你 | **称心** |
| 团队 ≥ 2 人 + 你想要现场互动 | **和而不同** |
| 你只想赢「文化表达」单项 | **称心** 或 **拈花** |

**我的判断**：如果 11/4 三个实验都按预期走，**称心**是这次的最优解；如果称心的机械或 AI 有一个不通，退回**零点**；如果两个都不通，**谛听**保底。

## 9. 11/4 必须做的三个实验（每个都能杀死/救活一个方案）

1. **称心的机械**：3D 打印（或买）一杆秤，舵机推游砣，测三档角度与回中误差。目标：倾角重复性 < 2°，回中 < 1 秒。不通 → 称心降级为「灯语版」（不倾，只亮三档），命题弱一半。
2. **称心的 AI**：录 10 句承诺（一定/尽量/发誓/随便/看情况/我保证/应该/尽量吧/明天/看吧），用 sherpa-onnx + LLM 打分，看排序是否符合直觉。若排序随机 → 换特征（加停顿/语速）或换模型；仍随机 → 放弃「称心」。
3. **和而不同的实时**：两个人哼两个音，手机上 demucs + 基频 + 生成第三声，测延迟。目标 < 300 ms。不通 → 改「预录 + 现场触发」，但会失去「活」的感觉。

**顺带验掉**：热敏打印机中文（零点）、板载麦能不能出 PCM（谛听/称心/零点共用）。
